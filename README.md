 # Revisao para SO (Sistema Operacional)

## 1- O que é o Sistema Operacional
Permite acessar e controlar o hardware da maquina, mudar recursos e interagir com aplicações diversas

---

## 2- Kernel
Componente principal do sistema operacional. É primeira parte do SO a ser carregado e fica na memoria principal

---

# Suas principais funções 

- Gerenciamento de **memória**
- Gerenciamento de **processos**
- Gerenciamento de **Armazenamento**
- Gerenciamento de **Dispositivos**

---

# Processos X Threads

**Processo** é um programa em execução. **Processos** são os programas que estão ocorrendo durante o uso.

**Threads** é um fluxo de segundo plano.
